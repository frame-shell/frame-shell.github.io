    frame install

    One command sets it up

    It asks how much you want (everything, app by app, or only the shell), which layout and which theme, notices a GoXLR, backs up what it replaces and links the rest. frame update pulls and applies again, frame status shows what is linked.

    ❯ ~/frameshell/frame install
